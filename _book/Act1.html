Análisis de los datos clínicos - Actividad 1

A través del análisis de un conjunto de datos clínicos, se busca identificar posibles asociaciones entre el uso de antibióticos y los resultados del tratamiento, medidos mediante la escala RCB (Residual Cancer Burden), la supervivencia y el riesgo de recaída.

Este estudio es relevante porque, aunque se ha explorado en otros tipos de cáncer, el impacto de los antibióticos en la respuesta neoadyuvante del cáncer de mama aún no está bien establecido. El análisis permitirá comprender mejor si el uso de antibióticos afecta la probabilidad de alcanzar una respuesta patológica completa, lo que podría tener implicaciones en la personalización del tratamiento oncológico.

Se han creado variables categóricas nuevas a partir de las originales para simplificar la interpretación. Los criterios utilizados han sido:

    • 1/2 → Grado 1 o 2
    • 3 → Grado 3
  • HISTOLOGIA_CAT:
    • DUCTAL → Tumores ductales
    • NO DUCTAL → Todos los demás tipos histológicos
  • Ki67_CAT:
    • <=14 → Marcador Ki-67 menor o igual a 14%
    • >14 → Mayor a 14%
  • FENOTIPO_IHQ_CAT:
    • LUMINAL → Fenotipos Luminal A o B
    • HER2 → Tumores HER2 o Luminal-HER2
    • TRIPLE NEGATIVO → Resto
  • ESTADIO_CAT:
    • I → Estadio I, IA, IB
    • II → II, IIA, IIB
    • III → III, IIIA, IIIB, IIIC
  • QT_CAT:
    • NO antiHER2 → Quimioterapia sin antiHER2
    • antiHER2 → Combinación con fármacos antiHER2

    • Una vez → 1 ciclo antibiótico

  • RCP: respuesta completa patológica calculada a partir de RCB:
    • SI → RCB-0 o RCB-1

Análisis de asociación/correlación

Para evaluar la posible relación entre la respuesta completa patológica (RCP) y las características de los pacientes, se emplearán análisis estadísticos adecuados a la naturaleza de cada variable. En el caso de las variables cualitativas, como el tipo de tratamiento o el estadio del tumor, se utilizarán pruebas diseñadas para comparar proporciones entre distintos grupos, como la prueba de Chi-cuadrado o, en situaciones donde el tamaño de la muestra sea reducido, la prueba exacta de Fisher. Estas herramientas permiten determinar si existen diferencias significativas en la distribución de estas características entre los pacientes que lograron o no una RCP.

Para las variables cuantitativas, como la edad del paciente o el índice de proliferación tumoral Ki67, se aplicarán pruebas que permitan evaluar diferencias en valores numéricos entre los grupos analizados. La prueba t de Student se empleará para comparar los valores promedio de estas variables entre los pacientes con y sin RCP, mientras que los coeficientes de correlación de Pearson o Spearman ayudarán a medir la intensidad y dirección de la relación entre estas características y la RCP.

A través de estos análisis se buscarán patrones o tendencias que puedan sugerir una asociación entre las características clínicas y patológicas de los pacientes y su respuesta al tratamiento. Los resultados obtenidos contribuirán a una mejor comprensión de los factores que podrían influir en la probabilidad de alcanzar una RCP, proporcionando información valiosa para optimizar estrategias terapéuticas y mejorar la toma de decisiones clínicas.

Explicación teórica

Antes de comenzar con el análisis estadístico, es fundamental comprender qué tipo de variables tenemos y cómo tratarlas según su naturaleza. Las técnicas estadísticas que se aplican varían dependiendo de si las variables son categóricas o numéricas.

Relación entre dos variables categóricas

Para analizar la relación entre dos variables categóricas, se comienza generando una tabla de contingencia, que nos muestra cuántas observaciones hay en cada combinación de categorías.

Dependiendo del número de observaciones en las celdas de la tabla, se elige uno de estos tests:

  • Si algún valor < 5 → Test de Fisher

  • Si todos los valores ≥ 5 → Test Chi-Cuadrado

Luego, se interpreta el resultado a través del p-valor:

Interpretación del p-valor
  • Si p < 0.05, se rechaza la hipótesis nula → Existe asociación estadística entre las variables.
  • Si p ≥ 0.05, no se rechaza la hipótesis nula → No hay evidencia de asociación.

Relación entre una variable categórica y una numérica

En este caso, el tipo de test dependerá de si la variable numérica sigue una distribución normal. Esto se evalúa con el test de Shapiro-Wilk:

  • Si p < 0.05 → No hay normalidad → Test de Wilcoxon

  • Si p ≥ 0.05 → Hay normalidad → Test t de Student

Nuevamente, el resultado se interpreta con el p-valor del test:

¿Existe asociación?
  • Si p < 0.05, se detecta una diferencia significativa entre los grupos.
  • Si p ≥ 0.05, no hay evidencia estadística de diferencia.

Relación entre dos variables numéricas

Cuando ambas variables son numéricas, se verifica su distribución con el test de Shapiro-Wilk. En función de los resultados, se selecciona el test de correlación apropiado:

  • Si ambas variables NO son normales → Correlación de Spearman

  • Si ambas variables son normales → Correlación de Pearson

Importante

Para aplicar el test de Pearson, ambas variables deben seguir distribución normal. Es decir, ambas deben tener p ≥ 0.05 en el test de Shapiro-Wilk.

Finalmente, el p-valor del test de correlación nos indicará si existe una relación estadísticamente significativa entre ambas variables.

Análisis multivariante

Se utilizarán métodos estadísticos avanzados para analizar cómo se relacionan varias variables entre sí y cuáles de ellas tienen mayor influencia sobre la probabilidad de que ocurra una respuesta completa patológica (RCP). En particular, se aplicará la regresión logística, una técnica que permite predecir la probabilidad de que ocurra un evento (en este caso, la RCP) a partir de otras variables. Luego, se evaluará la importancia de cada una de estas variables en el modelo, analizando factores como la significancia de los coeficientes (qué tan fuertes son las relaciones) y la calidad del modelo en general para ver cuán bien está prediciendo la RCP.

Explicación teórica

Con el objetivo de construir modelos que sean eficientes, interpretables y clínicamente relevantes, se implementarán técnicas de selección automática de variables. Estas técnicas permiten identificar un subconjunto óptimo de predictores basado en su contribución al modelo y a la explicación del evento RCP.

Técnicas de Selección Automática

Se utilizarán tres enfoques clásicos:

Selección hacia adelante (Forward Selection)

Parte de un modelo vacío e incorpora variables una por una, eligiendo en cada paso aquella que más mejora el modelo (según un criterio como AIC o BIC).

Ventaja: útil cuando hay muchas variables y se busca simplicidad.

Selección hacia atrás (Backward Elimination)

Parte de un modelo completo (con todas las variables) y elimina progresivamente las variables menos útiles.

Ventaja: considera la interacción total de las variables desde el inicio.

Selección bidireccional (Stepwise)

Combina ambos métodos: puede añadir o quitar variables en cada paso, dependiendo de si mejoran o no el modelo.

Ventaja: más flexible y generalmente logra modelos equilibrados.

Aplicación a Distintos Conjuntos de Variables

Para comprender cómo influyen las distintas variables en el modelo y validar el valor predictivo de la información seleccionada previamente, se aplicarán los métodos de selección automática a tres conjuntos de variables:

Modelo A: Variables Signficativas

Solo incluye aquellas variables que, en el análisis previo, mostraron una asociación estadísticamente significativa con `RCP`.

Objetivo: construir un modelo compacto y eficaz.

Modelo B: Variables no Significativas

Incluye únicamente las variables que no mostraron asociación estadística, pero se evaluará si pueden aportar valor en conjunto.

Objetivo: explorar posibles efectos combinados o no evidentes en análisis univariantes.

Modelo C: Todas las Variables

Considera todas las variables, independientemente de su significancia previa.

Objetivo: comparar el rendimiento del modelo global frente a los anteriores y verificar si hay variables descartadas prematuramente que son útiles.

Evaluación del Modelo

Cada modelo se evaluará en función de:

  • Criterios de información (AIC / BIC).

  • Calidad del ajuste (pseudo-R², estadísticos de bondad de ajuste).

  • Interpretabilidad clínica y parsimonia del modelo.

La comparación de los tres modelos permitirá determinar no solo qué variables resultan más útiles, sino también cómo influye la selección previa basada en pruebas de significancia en la calidad del modelo final.

Interpretaciones

Modelo A

Para el modelo A, se ha comprobado que la fórmula del modelo final es

RCP ~ FENOTIPO_IHQ_CAT + HT_ADY_OK + TAMAÑO + RP + Ki67_CAT

con idénticos valores estadísticos en los 3 modelos de selección, lo que sugiere una alta estabilidad del proceso de selección.

Métrica Valor
AIC 228.7
Residual deviance 202.70
Iteraciones 13

Los resultados del modelo sugieren que el fenotipo tumoral, el uso (o no) de hormonoterapia adyuvante, el tamaño tumoral, la expresión de receptores de progesterona (RP) y el índice de proliferación (Ki67) tienen un impacto relevante sobre la probabilidad de alcanzar una respuesta completa patológica (RCP).

En particular, el fenotipo triple negativo se asocia significativamente con una menor probabilidad de RCP. Aunque esto puede parecer contraintuitivo dependiendo del esquema de tratamiento, es coherente con la alta heterogeneidad biológica de este subtipo.

Por otro lado, no recibir hormonoterapia adyuvante se relaciona con una mayor probabilidad de RCP. Esto probablemente actúa como un indicador indirecto de subtipos tumorales más agresivos, como el triple negativo, que suelen ser más sensibles a la quimioterapia pero no hormonodependientes.

Modelo B

Para el modelo B cuya fórmula final es

RCP ~ ESTADIO_CAT + Nx + GRADO_CAT

Métrica Valor
AIC 122.42
Residual deviance 108.42
Iteraciones 15

En los tres enfoques de selección de variables para el Modelo B (forward, backward y stepwise), la variable GRADO_CAT3 (probablemente grado histológico 3) aparece consistentemente como un factor significativamente asociado a la probabilidad de respuesta completa patológica (RCP), con un efecto positivo.

En los modelos backward y stepwise (idénticos en este caso), también se identifica como significativa la categoría Nx2 (clasificación ganglionar), que se asocia negativamente con la RCP. El valor extremo y no significativo de Nx3 sugiere un bajo número de casos o posible colinealidad.

El modelo forward es más simple, incluyendo solo GRADO_CAT3, con mejor parsimonia pero menor ajuste. Los modelos backward y stepwise incorporan más variables, logrando un menor deviance residual aunque con mayor AIC.

RCP ~ RE + QT_CAT + Ki67_CAT

En los tres enfoques de selección de variables para el modelo C, la variable Ki67_CAT>14 (indicador de alta proliferación celular) aparece de manera consistente, aunque no es significativa en ninguno de los modelos, probablemente debido a alta varianza.

En el modelo forward, el receptor de estrógenos (RE) muestra una asociación negativa significativa con la probabilidad de respuesta completa patológica (RCP), mientras que ciertos esquemas de quimioterapia (QT_CATNO antiHER2) también presentan significación.

En los modelos backward y stepwise, se observa una asociación negativa significativa de la categoría Nx2 (afectación ganglionar) con la RCP. Además, el fenotipo triple negativo (FENOTIPO_IHQ_CATTRIPLE NEGATIVO) se asocia significativamente de forma negativa con la RCP, lo cual es coherente con su comportamiento clínico más agresivo.

La variable TAMAÑO del tumor también muestra una tendencia negativa marginalmente significativa (p ≈ 0.052), lo que podría indicar que tumores más grandes tienen menos probabilidad de lograr RCP.

Aunque el modelo forward es más parsimonioso (menos variables y menor AIC), los modelos backward y stepwise logran mejor ajuste (menor deviance residual), incorporando múltiples predictores clínicamente relevantes.

Análisis de supervivencia

Se llevó a cabo un análisis de supervivencia global (SG) con el objetivo de evaluar el impacto del uso de antibióticos en pacientes con cáncer de mama tratadas con quimioterapia neoadyuvante. El tiempo de seguimiento se calculó como la diferencia en meses entre la fecha de inicio del tratamiento (FECHA_INICIO_QT) y la fecha del último control (FECHA_ULTIMO_CONTROL). El evento de interés se definió como el fallecimiento de la paciente, codificado a partir de la variable ESTADO_ULTIMO_CONTROL (estado_SG = 1 si el estado es “MCE”, y 0 en caso contrario). Se estimaron curvas de Kaplan-Meier para evaluar la supervivencia global en el total de pacientes y se compararon las curvas según los subtipos moleculares del tumor (Luminal, HER2+, Triple Negativo), así como según el uso de antibióticos durante el tratamiento. Para evaluar diferencias estadísticas entre grupos se aplicó el test de log-rank. Finalmente, se repitió el análisis de supervivencia estratificado por subtipo molecular, comparando dentro de cada subtipo a las pacientes que recibieron antibióticos frente a las que no, con el fin de explorar si el efecto de los antibióticos sobre la supervivencia varía según el tipo biológico del cáncer.

# Preparar los datos
datos_preparados <- preparar_datos_supervivencia(dataset_recodificado)

# Ejecutar el análisis
resultados_sg <- analisis_supervivencia(datos_preparados)

# Mostrar los gráficos
resultados_sg$global

La probabilidad de supervivencia en la cohorte disminuye de manera progresiva y acentuada, especialmente a partir de los 270 meses de seguimiento, mostrando una tendencia que se aproxima a un descenso exponencial. Sin embargo, entre los 100 y 200 meses, la probabilidad aún se mantiene relativamente alta, oscilando entre 1 y 0.75.

Código 
resultados_sg$por_subtipo

En el análisis por subtipos moleculares, las pacientes con tumores Luminal experimentan una disminución brusca en la probabilidad de supervivencia alrededor de los 300 meses. En contraste, el subtipo HER2+ mantiene una probabilidad de supervivencia elevada, con valores que permanecen entre 1 y 0.75 a lo largo del tiempo analizado. Por su parte, el subtipo Triple Negativo muestra una caída más pronunciada en la probabilidad a partir de los 100 meses, aunque esta se mantiene por encima de 0.75 hasta aproximadamente los 250 meses, momento en el que desciende hasta 0.5 y alcanza un valor ligeramente superior a 0.25 en torno a los 300 meses.

Código 
resultados_sg$por_ab

En cuanto al uso de antibióticos, se observa que las pacientes que no recibieron antibióticos mantienen una probabilidad de supervivencia relativamente estable, que no desciende por debajo de 0.6 durante el período de seguimiento. En cambio, aquellas que sí recibieron antibióticos presentan una disminución gradual en la probabilidad de supervivencia, que se acentúa cerca de los 300 meses, momento en el cual la probabilidad cae bruscamente hasta alcanzar un valor próximo a 0.

resultados_sg$por_subtipo_y_ab[["LUMINAL"]]

Al analizar específicamente el subtipo LUMINAL, se observa que las pacientes que no recibieron antibióticos presentan una probabilidad de supervivencia muy similar a la de aquellas que sí los recibieron, manteniéndose ambas ligeramente por debajo de 1 a lo largo de los 300 meses de seguimiento.

Código 
resultados_sg$por_subtipo_y_ab[["HER2"]]

Al analizar específicamente el subtipo HER2+, se observa que las pacientes que no fueron tratadas con antibióticos mantienen una probabilidad de supervivencia constante de 1 durante todo el seguimiento. Por otro lado, aquellas que sí recibieron antibióticos muestran una probabilidad algo menor, situándose por encima de 0.75 antes de los 200 meses y manteniéndose estable en torno a 0.75 a partir de ese punto.

Código 
resultados_sg$por_subtipo_y_ab[["TRIPLE NEGATIVO"]]

Al analizar específicamente el subtipo TRIPLE NEGATIVO, se observa que las pacientes que no recibieron antibióticos presentan una menor probabilidad de supervivencia en comparación con aquellas que sí los recibieron. En este último grupo, la probabilidad de supervivencia se mantiene en 1 hasta aproximadamente los 250 meses de seguimiento. Esto podría sugerir un posible efecto beneficioso del uso de antibióticos en pacientes con este subtipo tumoral, contribuyendo a una mayor supervivencia.

Conclusiones

Los resultados obtenidos en este análisis de supervivencia sugieren que el uso de antibióticos durante el tratamiento con quimioterapia neoadyuvante podría estar asociado a una menor probabilidad de supervivencia en pacientes con cáncer de mama, particularmente en ciertos subtipos biológicos como HER2+ y LUMINAL. Estos hallazgos respaldan la hipótesis de que la alteración de la microbiota —posiblemente inducida por la administración de antibióticos— puede influir negativamente en la eficacia de las terapias oncológicas y, en consecuencia, en la evolución clínica de las pacientes.

En contraste, en el caso del subtipo TRIPLE NEGATIVO, se observa una tendencia opuesta: las pacientes que recibieron antibióticos presentan una mayor probabilidad de supervivencia en comparación con aquellas que no los recibieron. Este hallazgo sugiere que, en este subgrupo, el uso de antibióticos podría tener un efecto beneficioso, aunque se requiere un análisis más profundo para confirmar esta asociación y comprender los mecanismos subyacentes.Además, las diferencias observadas entre subtipos moleculares subrayan la necesidad de considerar el perfil biológico del tumor a la hora de valorar el riesgo asociado al uso de antibióticos durante el tratamiento oncológico. Esto sugiere que las decisiones clínicas relacionadas con la prescripción de antimicrobianos deberían realizarse con cautela, y en lo posible bajo un criterio de indicación estrictamente necesario, especialmente en el contexto de la quimioterapia.

Por otro lado, estos resultados también ponen de relieve la importancia de integrar el control de infecciones, la evaluación del estado inmunológico y la vigilancia de la microbiota intestinal como factores relevantes en el manejo integral de las pacientes con cáncer. En un futuro, este enfoque podría abrir la puerta a estrategias de soporte que busquen minimizar el impacto de los antibióticos o restaurar la microbiota, como el uso de probióticos o transplantes fecales, siempre dentro de un marco de evidencia científica robusta.

Finalmente, aunque este análisis no permite establecer relaciones causales definitivas, sí plantea interrogantes clínicamente relevantes que justifican la necesidad de realizar estudios prospectivos que analicen de forma más controlada el impacto de los antibióticos en la supervivencia, considerando la biología del tumor, las comorbilidades y la composición de la microbiota como posibles factores moduladores.
